# Coffee House Website

Responsive cafe website built with HTML, CSS and vanilla JavaScript.

## Included
- Responsive desktop/tablet/mobile layout
- Mobile navigation with keyboard Escape support
- Hero, About, Menu, Testimonials, Gallery and Contact sections
- User-provided cafe images placed in the `img` folder
- Scroll reveal animations with reduced-motion support
- Active navigation and back-to-top button
- Accessible labels, focus states and skip link

## Before publishing
Replace the placeholder email, phone number, address, opening hours and social-media `#` links with the real business details.

The contact form is front-end only. Connect it to Formspree, Netlify Forms or your own backend before using it for real messages.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the complete `img` folder.
3. Open **Settings → Pages**.
4. Select the branch containing `index.html`.
5. Save and open the generated GitHub Pages URL.


## Image assets

The supplied café images are included in `img/`. Layouts use `object-fit` to avoid stretching and preserve the original composition. High-resolution generated assets are used for the special-combo and dessert cards.
